Security & isolation

The whole stack is wired to be reproducible, minimal and safe for a student virtual machine.

  • TLS termination on NGINX (port 443 only), with TLS 1.2/1.3 enforced.
  • Configuration provided through a .env file, not hard‑coded in the images.
  • MariaDB hardened: no anonymous accounts, dedicated WordPress user, strong passwords.
  • All services attached to the same custom bridge network instead of host networking.

Architecture at a glance

Under the glassy surface, everything is driven by Docker Compose 3.8 using only Debian Bullseye based images you build yourself from the project sources.

  • WordPress and MariaDB store their data in bind‑mounted volumes under /home/macauchy/data/.
  • Services are declared with restart: always so the lab comes back after a reboot.
  • Redis accelerates WordPress by caching queries and objects in memory.
  • The static site is served separately by Lighttpd as a non‑PHP bonus service.
